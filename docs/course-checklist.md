# Technical Writing course checklist

Use this page to check the repository against the course outline before submitting it. A source file is not proof that an application was opened or an exercise was completed; keep your own output or screenshots where the course requires practical evidence.

| Syllabus item | Repository material | Evidence to keep |
|---|---|---|
| Documentation with Doxygen | [Doxygen guide](../02-code-documentation/doxygen/README.md) and C++ example | Generated HTML pages and a screenshot of the index |

## LaTeX topics

The examples also cover the detailed LaTeX items in the syllabus:

- Article and book classes, document sections and table of contents.
- Paper size, margins, headers, footers and page orientation.
- Text styles, alignment, colour, bullets and numbered lists.
- Mathematical expressions, matrices, summations and piecewise functions.
- Tables, borders, merged cells, images and captions.
- Labels, cross-references, bibliography and index.

See the [LaTeX guide](../01-document-authoring/latex/README.md) for the source files.

## Final review

- [ ] Every source file opens and has a clear purpose.
- [ ] LaTeX and Beamer examples compile without errors.
- [ ] Doxygen generates the HTML pages.
- [ ] The Google Docs exercise has been completed in the application.
- [ ] The repository README links work.
- [ ] No passwords, access tokens or private files have been committed.
