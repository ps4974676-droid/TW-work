# Project showcase: putting the tools together

A short technical report is a useful way to connect the topics in this course.

1. Draft and review the content in Google Docs.
2. Prepare the final report in LaTeX.
3. Add tables, figures, equations, captions and cross-references.
4. List the sources in a bibliography.
5. Prepare a short Beamer presentation based on the report.
6. If the project includes C++ code, document it with Doxygen.
7. Track source changes with Git and publish the project on GitHub.

## Evidence to collect for coursework

- A real Google Docs document or screenshots of its formatting and collaboration features.
- LaTeX source and the PDF produced from it.
- Beamer source and compiled slides.
- Doxygen source, configuration and generated HTML pages.
- Git commit history and the repository URL.

The examples in this repository are starting points. Replace sample material with your own work and keep the evidence of tools you actually used.
