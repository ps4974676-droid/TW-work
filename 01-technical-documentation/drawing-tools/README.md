# Drawing tools: Inkscape and Xfig

Vector drawing software is useful for diagrams that need to stay sharp when resized.

## A practical Inkscape workflow

1. Set the page size and orientation.
2. Draw shapes, lines and connectors.
3. Align and distribute related objects.
4. Keep colours, line widths and fonts consistent.
5. Group objects that belong together.
6. Add labels and arrows only where they help explain the figure.
7. Save the editable SVG and export a PDF or PNG for the report.

Xfig can also be used for simple technical drawings and can export figures for use in documents.

The editable diagram in `diagrams/document-workflow.svg` shows a basic document preparation process. Open it in Inkscape to inspect or change its objects.
