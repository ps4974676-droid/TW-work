# Google Docs: practical notes

Google Docs is useful for drafting, formatting and reviewing documents with other people.

## Start with structure

1. Create a document and give it a descriptive title.
2. Use the built-in Title, Heading 1, Heading 2 and Heading 3 styles.
3. Keep one main idea in each section.
4. Use the document outline to move around a longer report.

## Page setup

Open **File → Page setup** to choose paper size, orientation, page colour and margins. A4 portrait is a common starting point for a college report. Use **Insert → Page numbers** for pagination, and add headers or footers when they help identify the document.

## Formatting

Use paragraph styles instead of manually formatting every heading. Apply bold and italic for emphasis, and use actual numbered or bulleted lists rather than typing symbols by hand. Use the equation editor for mathematical expressions.

## Tables and images

Insert tables from **Insert → Table**. Give the columns clear headings and avoid overcrowding cells. Insert figures using **Insert → Image**, preserve their aspect ratio and add a caption that explains what the reader should notice.

## References and collaboration

Use the citation feature under **Tools → Citations** when it supports the required style. Keep the reference format consistent. Comments and Suggesting mode are useful during review; version history helps inspect earlier edits. When sharing, choose Viewer, Commenter or Editor according to the recipient's role.

## Exercise

Prepare a short report on computer networks with a title page, three heading levels, a numbered procedure, a bulleted list, one table, one image with a caption, page numbers and a references section.

## Final check

- [ ] Heading styles and spacing are consistent.
- [ ] Margins, orientation and page numbers are correct.
- [ ] Tables and images fit on the page.
- [ ] Sources are cited.
- [ ] Spelling and permissions have been checked.
