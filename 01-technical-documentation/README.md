# Documentation tools

This section covers the tools used to prepare written material, document source code and draw supporting diagrams.

- [Google Docs](google-docs/README.md): styles, page setup, tables, images, citations and collaboration.
- [Doxygen](doxygen/README.md): documenting C++ source and generating HTML reference pages.
- [Drawing tools](drawing-tools/README.md): a practical vector-drawing workflow for Inkscape and Xfig.

A good technical document is accurate, organized around its reader, consistent in style and clear about where its information comes from.
