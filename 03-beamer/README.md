# Beamer presentations

Beamer is a LaTeX document class for slide presentations. The source file in this folder demonstrates a title slide, table of contents, frames, sections, columns, blocks, lists and an equation.

Compile it with:

```bash
pdflatex presentation.tex
pdflatex presentation.tex
```

The output is a PDF slide deck. Change the title, author and examples to match the topic of your own presentation.
