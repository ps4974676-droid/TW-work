# Project showcase: putting the tools together

A small report on computer networks is a useful way to connect the topics in this course.

1. Draft and review the content in Google Docs.
2. Draw a network diagram in Inkscape and save the editable SVG.
3. Prepare the final report in LaTeX.
4. Add tables, figures, equations, captions and cross-references.
5. List the sources in a bibliography.
6. Prepare a short Beamer presentation based on the report.
7. If the project includes C++ code, document it with Doxygen.
8. Plot measured data with Gnuplot.
9. Track source changes with Git and publish the project on GitHub.

## Evidence to collect for coursework

- A real Google Docs document or screenshots of its formatting and collaboration features.
- LaTeX source and the PDF produced from it.
- Beamer source and compiled slides.
- Doxygen source, configuration and generated HTML pages.
- Editable drawing source.
- Gnuplot input data, script and resulting graph.
- Git commit history and the repository URL.

The examples in this repository are starting points. Replace sample material with your own work and keep the evidence of tools you actually used.
