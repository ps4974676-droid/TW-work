# Complete report template

The `report.tex` file combines several features from the LaTeX section: report class, title page, abstract, table of contents, page headers, mathematics, tables, labels, cross-references and bibliography.

Compile from this directory:

```bash
pdflatex report.tex
pdflatex report.tex
```

The second run updates cross-references and lists. The template is a starting point; add a real figure, expand the discussion and verify all references before using it as a submitted report.
