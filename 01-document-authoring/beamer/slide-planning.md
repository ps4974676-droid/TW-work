# Planning a Beamer presentation

A slide deck should follow the same argument as the report, but it should not copy entire paragraphs onto slides.

## A workable sequence

1. Title: topic, presenter and course.
2. Outline: the sections the audience will hear.
3. Context: explain the problem or background.
4. Main points: one idea per frame, supported by an example or figure.
5. Evidence: use a table, diagram or graph only when it adds information.
6. Conclusion: return to the main message.
7. Questions: leave a final frame for discussion.

## Layout checks

- Use a consistent theme and font sizes.
- Keep text and figures within the slide margins.
- Use columns only when two items genuinely need to be compared.
- Use blocks to group related information, not to decorate every paragraph.
- Check the PDF in presentation mode before sharing it.
