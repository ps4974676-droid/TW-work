# Beamer screenshot gallery

These six topic-wise SVG illustrations show a recreated Beamer/TeXstudio workflow. They are **mock editor views**, not original screenshots captured from a live TeXstudio session.

## Topics

1. [Title slide and themes](./01-title-theme.svg) — Create a title slide and apply a presentation theme
2. [Sections and frames](./02-sections-frames.svg) — Organize slides into sections and frames
3. [Lists and columns](./03-lists-columns.svg) — Use bullet lists and a two-column layout
4. [Mathematical equations](./04-equations.svg) — Insert a numbered mathematical equation
5. [Figures and tables](./05-figures-tables.svg) — Place a figure and a compact table on slides
6. [Overlays and transitions](./06-overlays.svg) — Reveal bullet points step by step
