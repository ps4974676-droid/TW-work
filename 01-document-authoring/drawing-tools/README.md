# Drawing tools: Inkscape and Xfig

Drawing tools are useful for making diagrams that explain a process, system or relationship more clearly than a paragraph alone.

## Inkscape

Inkscape is a vector graphics editor. Vector objects such as paths, shapes and text can be resized without becoming pixelated. It is suitable for flowcharts, labelled diagrams and simple illustrations.

Practise creating shapes, lines and arrows; aligning and distributing objects; grouping related items; and saving an editable SVG. Export a PDF or PNG copy when a document needs a static figure.

The editable [document workflow diagram](document-workflow.svg) is included as a small example. Open it in Inkscape to inspect or change its objects.

## Xfig

Xfig is a vector drawing program often used for technical illustrations. It supports objects such as lines, boxes, arcs, splines and text. Save the editable drawing in its native format and export it to a format accepted by the document where it will be used.

## Before inserting a diagram

Check that text remains readable at the final page size, arrows point in the intended direction, labels are consistent, and the figure has a caption in the report.
