# Google Docs screenshot gallery

These six topic-wise SVG illustrations show a recreated Google Docs workflow. They are **mock editor views**, not original screenshots captured from Google Docs.

## Topics

1. [Styles and headings](./01-styles-headings.svg) — Apply title, heading and paragraph styles
2. [Page setup and layout](./02-page-layout.svg) — Set page size, margins, orientation and spacing
3. [Tables and images](./03-tables-images.svg) — Insert a table and position an image
4. [Equations and special symbols](./04-equations.svg) — Insert mathematical expressions using equation tools
5. [Table of contents](./05-table-of-contents.svg) — Generate a contents list from heading styles
6. [Citations and collaboration](./06-citations-comments.svg) — Add citations, comments and suggestions
