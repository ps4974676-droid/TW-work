# Google Docs

Google Docs is a browser-based word processor. It is useful when a document needs to be drafted, formatted, reviewed and shared with other people.

## Document workflow

1. Create a blank document or start from a template.
2. Give the document a clear title and use Heading 1, Heading 2 and Heading 3 styles instead of manually enlarging every heading.
3. Use the page setup options to choose paper size, orientation and margins.
4. Insert tables, images, captions and page numbers where they help the reader.
5. Use the spelling and grammar suggestions, then read the document once without relying on the suggestions.
6. Use comments and Suggesting mode when someone else is reviewing the work.
7. Set sharing permissions deliberately: Viewer, Commenter or Editor.
8. Download a final copy as PDF or Microsoft Word when a submission requires it.

## Features to practise

- **Styles and outline:** consistent headings also build the document outline.
- **Page layout:** margins, page orientation, headers, footers and page numbers.
- **Insert menu:** tables, images, drawings, links, equations and special characters.
- **Review:** comments, suggestions, version history and resolving comments.
- **Sharing:** restricted access or link-based access with an appropriate role.

## Suggested practical exercise

Prepare a two-page note on a technical topic. Include a title, a short introduction, at least two heading levels, one table, one image with a caption, page numbers and a references section. Share it with a classmate as a commenter and make one revision after receiving feedback.

Google Docs is an application, so this guide cannot show a live document from your account. Keep your own document link or screenshots as evidence of the exercise.
