# Technical report outline for Google Docs

Use this outline as a starting point for a short course report. Replace the prompts with your own writing and remove any section that is not relevant.

## Title

Write a specific title that tells the reader what the report is about.

## Abstract

In a short paragraph, state the problem or topic, what the report covers and the main conclusion.

## 1. Introduction

Explain the background and why the topic matters. State the purpose and scope of the report.

## 2. Main discussion

### 2.1 First point

Explain the first idea and define any technical terms.

### 2.2 Second point

Use a table, figure or example if it makes the explanation easier to follow.

## 3. Conclusion

Summarize the main findings. Do not introduce a new argument here.

## References

List every source used in the report in one consistent citation style.

## Formatting reminders

- Apply Heading styles from the Google Docs toolbar.
- Insert a table of contents after applying the heading styles.
- Add page numbers and useful headers or footers.
- Give every table and figure a descriptive title or caption.
- Use comments or Suggesting mode when asking someone to review the draft.
